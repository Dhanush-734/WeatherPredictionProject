# Weather Prediction Project

This project demonstrates a complete machine learning workflow for predicting temperature from weather-related features.

## Structure
- dataset/: raw and cleaned weather datasets
- notebooks/: step-by-step analysis and modeling notebooks
- models/: trained model artifacts
- output/: predictions, graphs, and reports
- streamlit/: interactive prediction app

## Quick start
1. Install dependencies: `pip install -r requirements.txt`
2. Train the model: `python train_model.py`
3. Launch the app: `streamlit run streamlit/app.py`
